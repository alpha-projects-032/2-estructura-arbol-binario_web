Operaciones fundamentales de los árboles binarios

Comprender la creación, inserción, búsqueda, eliminación, consulta y validación de nodos en árboles binarios utilizando Python.

Introducción

Los árboles binarios permiten organizar información mediante relaciones jerárquicas entre nodos. Además de representar datos, ofrecen diferentes operaciones para administrar dinámicamente los elementos almacenados.

Entre estas operaciones se encuentran la creación, inserción, búsqueda, eliminación y consulta de nodos, así como la validación de condiciones necesarias para prevenir errores.

El comportamiento de estas operaciones depende del tipo de árbol y de las reglas utilizadas para organizar sus elementos.

En este contenido se utilizará principalmente el árbol binario de búsqueda (BST), que organiza los valores mediante comparaciones y permite estudiar las operaciones fundamentales utilizando Python.

3.1 Creación e inicialización de un árbol binario

La creación de un árbol binario consiste en establecer una estructura capaz de almacenar nodos y mantener referencias hacia sus hijos izquierdo y derecho.

En Python, los árboles binarios pueden implementarse mediante clases y objetos. Cada nodo almacena un valor y dos referencias que permiten establecer conexiones con otros nodos.

Valor

Información almacenada dentro del nodo.

Referencia izquierda

Conexión hacia el hijo izquierdo.

Referencia derecha

Conexión hacia el hijo derecho.

Definición de la clase Nodo

class Nodo:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None
Explicación del código
  • Nodo representa cada elemento del árbol.
  • __init__() inicializa los atributos del objeto.
  • valor almacena la información.
  • izquierdo y derecho representan las referencias hacia los hijos.
  • None indica la ausencia de una conexión hacia otro nodo.

Creación de la clase ArbolBinario

class ArbolBinario:
    def __init__(self):
        self.raiz = None

La clase ArbolBinario administra la estructura mediante el atributo raiz. Inicialmente, este atributo contiene None, indicando que el árbol se encuentra vacío.

Inicialización del árbol

arbol = ArbolBinario()

print(arbol.raiz)
None

Creación del primer nodo

arbol.raiz = Nodo(50)

print("Raíz:", arbol.raiz.valor)

Figura 1. Árbol inicializado con un nodo.

Una vez creada la raíz, el árbol está preparado para incorporar nuevos nodos mediante operaciones de inserción.

3.2 Inserción de nodos

La inserción consiste en incorporar un nuevo elemento al árbol binario. La posición donde se almacena depende de las reglas de organización utilizadas.

En un árbol binario de búsqueda (BST), los valores menores se colocan en el subárbol izquierdo y los mayores en el subárbol derecho.

Reglas de inserción

Valor menor

Se continúa hacia el subárbol izquierdo.

Valor mayor

Se continúa hacia el subárbol derecho.

Valor duplicado

En esta implementación, los valores repetidos no se insertan.

Ejemplo de inserción

Se insertarán los siguientes valores numéricos en orden:

50   30   70   20   40   60   80
  1. El valor 50 se convierte en la raíz.
  2. 30 es menor que 50 y se inserta a la izquierda.
  3. 70 es mayor que 50 y se inserta a la derecha.
  4. 20 es menor que 50 y 30; se coloca a la izquierda de 30.
  5. 40 es menor que 50, pero mayor que 30; se coloca a la derecha de 30.
  6. 60 es mayor que 50, pero menor que 70; se inserta a la izquierda de 70.
  7. 80 es mayor que 50 y 70; se inserta a la derecha de 70.

Figura 2. Árbol binario de búsqueda con siete valores.

Implementación en Python

El siguiente código amplía la clase ArbolBinario para permitir la inserción de valores únicos.

class ArbolBinario:
    def __init__(self):
        self.raiz = None

    def insertar(self, valor):
        if self.raiz is None:
            self.raiz = Nodo(valor)
        else:
            self._insertar_recursivo(self.raiz, valor)

    def _insertar_recursivo(self, nodo, valor):
        if valor < nodo.valor:
            if nodo.izquierdo is None:
                nodo.izquierdo = Nodo(valor)
            else:
                self._insertar_recursivo(
                    nodo.izquierdo, valor
                )

        elif valor > nodo.valor:
            if nodo.derecho is None:
                nodo.derecho = Nodo(valor)
            else:
                self._insertar_recursivo(
                    nodo.derecho, valor
                )

Ejemplo de uso

arbol = ArbolBinario()

valores = [50, 30, 70, 20, 40, 60, 80]

for valor in valores:
    arbol.insertar(valor)
El método insertar() administra la incorporación de valores. La función recursiva compara cada elemento y continúa por el subárbol correspondiente hasta encontrar una posición disponible.

3.3 Búsqueda de elementos

La búsqueda permite determinar si un valor se encuentra almacenado en el árbol.

En un árbol binario general podría ser necesario examinar numerosos nodos. En un BST, las comparaciones permiten seleccionar el subárbol donde podría encontrarse el elemento.

Valor encontrado

La búsqueda termina cuando existe coincidencia.

Valor menor o mayor

Se continúa por el subárbol correspondiente.

Referencia vacía

Si se alcanza None, el valor no existe.

Ejemplo: búsqueda del valor 40

Figura 3. Ruta de búsqueda: 50 → 30 → 40.

  1. Se compara 40 con 50; como es menor, se continúa a la izquierda.
  2. Se compara 40 con 30; como es mayor, se continúa a la derecha.
  3. Se encuentra el nodo 40 y finaliza la búsqueda.

Implementación en Python

Los siguientes métodos deben incorporarse a la clase ArbolBinario.

def buscar(self, valor):
    return self._buscar_recursivo(
        self.raiz, valor
    )

def _buscar_recursivo(self, nodo, valor):
    if nodo is None:
        return False

    if nodo.valor == valor:
        return True

    if valor < nodo.valor:
        return self._buscar_recursivo(
            nodo.izquierdo, valor
        )

    return self._buscar_recursivo(
        nodo.derecho, valor
    )

Ejemplo de uso

print(arbol.buscar(40))
print(arbol.buscar(90))

Resultado esperado

True
False

Eficiencia de la búsqueda

La eficiencia depende de la altura del árbol. En un BST equilibrado con altura logarítmica, la búsqueda puede realizarse en tiempo O(log n).

Si el árbol está degenerado, puede ser necesario recorrer todos sus nodos, alcanzando una complejidad de O(n).

3.4 Eliminación de nodos

La eliminación permite retirar un nodo del árbol. En un BST, es necesario conservar las reglas de ordenamiento después de realizar esta operación.

El procedimiento depende de la cantidad de hijos que posee el nodo que se desea eliminar.

Caso 1. Eliminación de un nodo hoja

Un nodo hoja no posee hijos. Se elimina retirando la referencia correspondiente desde su nodo padre.
Antes
Después

Caso 2. Eliminación de un nodo con un hijo

Si el nodo tiene un único hijo, este ocupa la posición del nodo eliminado, actualizando la referencia correspondiente.
Antes
Después

Caso 3. Eliminación de un nodo con dos hijos

Cuando un nodo posee dos hijos, puede reemplazarse su valor por el sucesor inorden, que es el menor valor del subárbol derecho.

Otra estrategia válida es utilizar el predecesor inorden, correspondiente al mayor valor del subárbol izquierdo.

Ejemplo: eliminación del valor 50

Figura 4. Nodo 50 que será reemplazado por su sucesor 60.

  1. Se localiza el subárbol derecho del nodo 50.
  2. Se identifica el valor mínimo, que es 60.
  3. Se reemplaza el valor 50 por 60.
  4. Se elimina el nodo original que contenía 60.

Implementación en Python

Los siguientes métodos se incorporan a la clase ArbolBinario.

def eliminar(self, valor):
    self.raiz = self._eliminar_recursivo(
        self.raiz, valor
    )

def _eliminar_recursivo(self, nodo, valor):
    if nodo is None:
        return None

    if valor < nodo.valor:
        nodo.izquierdo = self._eliminar_recursivo(
            nodo.izquierdo, valor
        )

    elif valor > nodo.valor:
        nodo.derecho = self._eliminar_recursivo(
            nodo.derecho, valor
        )

    else:
        # Caso 1 y caso 2
        if nodo.izquierdo is None:
            return nodo.derecho

        if nodo.derecho is None:
            return nodo.izquierdo

        # Caso 3: nodo con dos hijos
        sucesor = self._encontrar_minimo(
            nodo.derecho
        )

        nodo.valor = sucesor.valor

        nodo.derecho = self._eliminar_recursivo(
            nodo.derecho, sucesor.valor
        )

    return nodo

def _encontrar_minimo(self, nodo):
    while nodo.izquierdo is not None:
        nodo = nodo.izquierdo

    return nodo

Ejemplo de uso

arbol.eliminar(50)

print("Nueva raíz:", arbol.raiz.valor)
Nueva raíz: 60
La eliminación actualiza las referencias necesarias para conservar la organización del árbol binario de búsqueda.

3.5 Consulta de nodos y relaciones

La consulta permite obtener información sobre los nodos y las relaciones que mantienen dentro del árbol sin modificar su contenido.

Consulta de la raíz

Obtener el valor del nodo principal.

Consulta de hijos

Obtener las referencias izquierda y derecha.

Identificación de hojas

Determinar si un nodo carece de hijos.

Cantidad de hijos

Identificar el grado de un nodo.

Consulta de la raíz

print("Raíz:", arbol.raiz.valor)

Consulta de los hijos

Antes de consultar un hijo, es importante verificar que exista la referencia correspondiente.

if arbol.raiz is not None:
    if arbol.raiz.izquierdo is not None:
        print("Hijo izquierdo:",
              arbol.raiz.izquierdo.valor)

    if arbol.raiz.derecho is not None:
        print("Hijo derecho:",
              arbol.raiz.derecho.valor)

Verificación de un nodo hoja

def es_hoja(nodo):
    return (
        nodo is not None
        and nodo.izquierdo is None
        and nodo.derecho is None
    )

La función devuelve True cuando el nodo existe y no posee hijos. En cualquier otra situación devuelve False.

Consulta de la cantidad de hijos

def contar_hijos(nodo):
    if nodo is None:
        return 0

    cantidad = 0

    if nodo.izquierdo is not None:
        cantidad += 1

    if nodo.derecho is not None:
        cantidad += 1

    return cantidad

Ejemplo de uso

print(contar_hijos(arbol.raiz))
Si la raíz posee dos hijos, el resultado será 2. Las consultas permiten examinar la estructura y verificar sus propiedades antes de efectuar modificaciones.

3.6 Validación de árboles vacíos y nodos inexistentes

La validación consiste en comprobar determinadas condiciones antes de ejecutar una operación. Esto permite prevenir errores y administrar situaciones especiales dentro del programa.

Verificación de un árbol vacío

Un árbol está vacío cuando su raíz contiene None.

def esta_vacio(self):
    return self.raiz is None

Este método debe incorporarse dentro de la clase ArbolBinario.

Ejemplo de uso

arbol = ArbolBinario()

print(arbol.esta_vacio())

arbol.insertar(50)

print(arbol.esta_vacio())
True
False

Validación antes de consultar la raíz

if arbol.esta_vacio():
    print("El árbol está vacío")
else:
    print("Raíz:", arbol.raiz.valor)

Validación de nodos inexistentes

valor = 90

if arbol.buscar(valor):
    print("El nodo existe")
else:
    print("El nodo no existe")

Validación antes de eliminar

valor = 90

if arbol.buscar(valor):
    arbol.eliminar(valor)
    print("Nodo eliminado correctamente")
else:
    print("No se puede eliminar: nodo inexistente")

Principales validaciones

Validación Condición Propósito
Árbol vacío raiz is None Evitar acceder a una raíz inexistente.
Nodo inexistente buscar() == False Identificar valores no almacenados.
Hijo izquierdo inexistente nodo.izquierdo is None Evitar referencias inválidas.
Hijo derecho inexistente nodo.derecho is None Evitar referencias inválidas.
Nodo hoja Ambos hijos son None. Identificar nodos terminales.
Valor duplicado El valor ya existe. Mantener la política de valores únicos.
Las validaciones contribuyen a desarrollar programas más confiables y facilitan el manejo de situaciones especiales durante las operaciones de los árboles binarios.

Ejemplo práctico integral en Python

El siguiente programa reúne las operaciones de creación, inserción, búsqueda, eliminación, consulta y validación de un árbol binario de búsqueda.

Esta implementación utiliza valores numéricos únicos y permite ejecutar las operaciones principales mediante una clase denominada ArbolBinario.
class Nodo:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None


class ArbolBinario:
    def __init__(self):
        self.raiz = None

    def esta_vacio(self):
        return self.raiz is None

    def insertar(self, valor):
        self.raiz = self._insertar(
            self.raiz, valor
        )

    def _insertar(self, nodo, valor):
        if nodo is None:
            return Nodo(valor)

        if valor < nodo.valor:
            nodo.izquierdo = self._insertar(
                nodo.izquierdo, valor
            )

        elif valor > nodo.valor:
            nodo.derecho = self._insertar(
                nodo.derecho, valor
            )

        return nodo

    def buscar(self, valor):
        nodo = self.raiz

        while nodo is not None:
            if valor == nodo.valor:
                return True

            if valor < nodo.valor:
                nodo = nodo.izquierdo
            else:
                nodo = nodo.derecho

        return False

    def eliminar(self, valor):
        self.raiz = self._eliminar(
            self.raiz, valor
        )

    def _eliminar(self, nodo, valor):
        if nodo is None:
            return None

        if valor < nodo.valor:
            nodo.izquierdo = self._eliminar(
                nodo.izquierdo, valor
            )

        elif valor > nodo.valor:
            nodo.derecho = self._eliminar(
                nodo.derecho, valor
            )

        else:
            if nodo.izquierdo is None:
                return nodo.derecho

            if nodo.derecho is None:
                return nodo.izquierdo

            sucesor = nodo.derecho

            while sucesor.izquierdo is not None:
                sucesor = sucesor.izquierdo

            nodo.valor = sucesor.valor

            nodo.derecho = self._eliminar(
                nodo.derecho, sucesor.valor
            )

        return nodo

    def obtener_raiz(self):
        if self.esta_vacio():
            return None

        return self.raiz.valor


# Crear el árbol
arbol = ArbolBinario()

# Insertar valores
valores = [50, 30, 70, 20, 40, 60, 80]

for valor in valores:
    arbol.insertar(valor)

# Consultar información
print("Árbol vacío:", arbol.esta_vacio())
print("Raíz:", arbol.obtener_raiz())

# Buscar valores
print("Buscar 40:", arbol.buscar(40))
print("Buscar 90:", arbol.buscar(90))

# Eliminar un nodo
arbol.eliminar(50)

# Consultar nueva raíz
print("Nueva raíz:", arbol.obtener_raiz())

Resultado esperado

Árbol vacío: False
Raíz: 50
Buscar 40: True
Buscar 90: False
Nueva raíz: 60

Explicación del funcionamiento

  • Se crea un árbol vacío mediante la clase ArbolBinario.
  • Se insertan siete valores numéricos utilizando un ciclo for.
  • El método esta_vacio() verifica si existen nodos almacenados.
  • obtener_raiz() permite consultar el valor de la raíz.
  • buscar() determina si un valor existe dentro del árbol.
  • eliminar() retira un nodo y actualiza las referencias necesarias para conservar la organización del BST.

Al eliminar el valor 50, su posición es ocupada por el sucesor inorden, que contiene el valor 60.

Comparación de las operaciones fundamentales

Operación Descripción Resultado
Creación Inicializa la estructura. Árbol vacío o con raíz.
Inserción Incorpora un nuevo nodo. Se agrega un elemento.
Búsqueda Localiza un valor. Indica si existe.
Eliminación Retira un nodo. Se actualiza la estructura.
Consulta Obtiene información de los nodos. Devuelve valores o relaciones.
Validación Comprueba condiciones. Previene errores y operaciones inválidas.

Síntesis

Las operaciones fundamentales permiten construir y administrar árboles binarios mediante la creación, inserción, búsqueda, eliminación y consulta de nodos.

En los árboles binarios de búsqueda, las comparaciones entre valores permiten seleccionar los subárboles correspondientes. La eliminación requiere considerar si el nodo posee cero, uno o dos hijos.

Las validaciones permiten identificar árboles vacíos, nodos inexistentes y referencias inválidas, contribuyendo a desarrollar programas más confiables.

La implementación de estas operaciones en Python proporciona la base para trabajar con estructuras jerárquicas y desarrollar algoritmos de recorrido y procesamiento de árboles binarios.
