Implementación y aplicaciones de árboles binarios en Python

Construir y manipular árboles binarios mediante clases en Python, implementando operaciones de búsqueda, inserción, eliminación y aplicaciones prácticas.

Introducción

Los árboles binarios son estructuras de datos no lineales que permiten organizar información mediante relaciones jerárquicas entre nodos. Su implementación en Python facilita el desarrollo de programas capaces de almacenar, consultar y procesar datos dinámicamente.

Después de estudiar sus fundamentos, tipos, operaciones y recorridos, es posible integrar estos conocimientos mediante la programación orientada a objetos.

En este contenido se utilizará principalmente el árbol binario de búsqueda (BST), que organiza valores mediante reglas de comparación.

También se estudiarán aplicaciones relacionadas con la gestión de registros, la representación de expresiones matemáticas y los procesos de decisión.

5.1 Creación de una clase Node

En Python, un árbol binario puede implementarse mediante clases y objetos. Cada nodo se representa como un objeto que almacena información y mantiene referencias hacia sus posibles hijos.

La clase Node representa la unidad básica de un árbol binario. Cada objeto contiene un valor y dos referencias: una hacia el hijo izquierdo y otra hacia el hijo derecho.

Estructura de un nodo

Atributo Descripción
value Almacena el valor o información del nodo.
left Referencia hacia el hijo izquierdo.
right Referencia hacia el hijo derecho.

Implementación de la clase Node

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
Explicación del código
  • class Node define la clase que representa los nodos.
  • __init__() inicializa los atributos del objeto.
  • self.value almacena el valor recibido.
  • self.left representa la referencia hacia el hijo izquierdo.
  • self.right representa la referencia hacia el hijo derecho.
  • None indica que no existe un hijo en esa posición.

Creación de un nodo

node = Node(50)

print("Valor:", node.value)
print("Hijo izquierdo:", node.left)
print("Hijo derecho:", node.right)

Resultado esperado

Valor: 50
Hijo izquierdo: None
Hijo derecho: None

Figura 1. Representación de un nodo con sus referencias iniciales.

La clase Node permite crear tantos nodos como sean necesarios y establecer conexiones entre ellos para construir estructuras jerárquicas.

5.2 Implementación de una clase BinaryTree

La clase Node permite crear elementos individuales. Sin embargo, para administrar una estructura completa resulta conveniente implementar una clase que mantenga la referencia de la raíz y proporcione las operaciones necesarias.

La clase BinaryTree administra los nodos del árbol. En esta implementación se utilizarán las reglas de un árbol binario de búsqueda con valores numéricos únicos.

Estructura de la clase

class BinaryTree:
    def __init__(self):
        self.root = None

El atributo root almacena la referencia hacia la raíz del árbol. Inicialmente contiene None, porque todavía no existen nodos.

Creación de un árbol vacío

tree = BinaryTree()

print(tree.root)
None

Incorporación del método insert()

El método de inserción utiliza las reglas de comparación del BST para determinar la posición de cada nuevo valor.

class BinaryTree:
    def __init__(self):
        self.root = None

    def insert(self, value):
        self.root = self._insert(
            self.root, value
        )

    def _insert(self, node, value):
        if node is None:
            return Node(value)

        if value < node.value:
            node.left = self._insert(
                node.left, value
            )

        elif value > node.value:
            node.right = self._insert(
                node.right, value
            )

        return node
Funcionamiento de insert()
  • Recibe el valor que se desea almacenar.
  • Compara el valor con los nodos existentes.
  • Si es menor, continúa hacia el subárbol izquierdo.
  • Si es mayor, continúa hacia el subárbol derecho.
  • Cuando encuentra una referencia vacía, crea un nuevo nodo.
  • Los valores duplicados no se incorporan en esta implementación.

Ejemplo de uso

tree = BinaryTree()

tree.insert(50)
tree.insert(30)
tree.insert(70)

print("Raíz:", tree.root.value)
print("Izquierda:", tree.root.left.value)
print("Derecha:", tree.root.right.value)

Resultado esperado

Raíz: 50
Izquierda: 30
Derecha: 70

Figura 2. Árbol construido mediante BinaryTree.

Separar las clases Node y BinaryTree facilita la organización, reutilización y ampliación del código.

5.3 Construcción y manipulación de árboles binarios

La manipulación de árboles binarios comprende las operaciones necesarias para insertar, buscar, recorrer y eliminar elementos. Estas operaciones permiten administrar dinámicamente la información almacenada.

Inserción de varios elementos

Se utilizarán los siguientes valores:

50   30   70   20   40   60   80
tree = BinaryTree()

values = [50, 30, 70, 20, 40, 60, 80]

for value in values:
    tree.insert(value)

Figura 3. Árbol binario de búsqueda con siete valores.

Implementación de la búsqueda

El método search() determina si un valor existe dentro del árbol utilizando comparaciones sucesivas.

Los siguientes métodos se incorporan a la clase BinaryTree.

def search(self, value):
    current = self.root

    while current is not None:
        if value == current.value:
            return True

        if value < current.value:
            current = current.left
        else:
            current = current.right

    return False

Ejemplo de búsqueda

print(tree.search(40))
print(tree.search(90))
True
False

Implementación del recorrido inorden

El método inorder() permite obtener una lista con todos los valores almacenados en el BST en orden ascendente.

def inorder(self):
    result = []
    self._inorder(self.root, result)
    return result

def _inorder(self, node, result):
    if node is not None:
        self._inorder(node.left, result)
        result.append(node.value)
        self._inorder(node.right, result)

Ejemplo de uso

print(tree.inorder())
[20, 30, 40, 50, 60, 70, 80]
Este método devuelve una lista que puede utilizarse posteriormente en otras operaciones, a diferencia de una función que únicamente muestra los valores mediante print().

Implementación de la eliminación

El método delete() permite retirar un nodo y mantener las propiedades del BST, considerando si posee cero, uno o dos hijos.

def delete(self, value):
    self.root = self._delete(
        self.root, value
    )

def _delete(self, node, value):
    if node is None:
        return None

    if value < node.value:
        node.left = self._delete(
            node.left, value
        )

    elif value > node.value:
        node.right = self._delete(
            node.right, value
        )

    else:
        if node.left is None:
            return node.right

        if node.right is None:
            return node.left

        successor = node.right

        while successor.left is not None:
            successor = successor.left

        node.value = successor.value

        node.right = self._delete(
            node.right, successor.value
        )

    return node

Ejemplo de eliminación

tree.delete(30)

print(tree.inorder())
[20, 40, 50, 60, 70, 80]

El valor 30 se elimina. Como posee dos hijos, se utiliza el sucesor inorden 40 para mantener la organización del árbol.

Operaciones implementadas

Método Operación Resultado
insert() Inserción. Agrega un nuevo nodo.
search() Búsqueda. Devuelve True o False.
inorder() Recorrido. Devuelve una lista ordenada.
delete() Eliminación. Retira un nodo.

5.4 Introducción a los árboles binarios de búsqueda (BST)

Un árbol binario de búsqueda (BST) es un tipo de árbol binario que organiza sus valores mediante reglas de comparación, facilitando las operaciones de inserción, búsqueda y eliminación.

Propiedades fundamentales

Subárbol izquierdo

Contiene valores menores que el nodo actual.

Subárbol derecho

Contiene valores mayores que el nodo actual.

Ordenamiento

El recorrido inorden permite obtener valores ascendentes.

Estas propiedades deben cumplirse recursivamente en todos los subárboles del BST.

Ejemplo: búsqueda del valor 60

Figura 4. Ruta de búsqueda: 50 → 70 → 60.

  1. Se compara 60 con 50. Como es mayor, se continúa hacia la derecha.
  2. Se compara 60 con 70. Como es menor, se continúa hacia la izquierda.
  3. Se encuentra el nodo 60 y finaliza la búsqueda.

En este ejemplo solamente se examinan tres nodos, en lugar de recorrer toda la estructura.

Eficiencia de un BST

Operación BST con altura logarítmica BST degenerado
Inserción O(log n) O(n)
Búsqueda O(log n) O(n)
Eliminación O(log n) O(n)

Ejemplo de árbol degenerado

Si los valores se insertan en orden ascendente, el BST puede formar una estructura similar a una lista enlazada.

10   20   30   40   50

Figura 5. BST degenerado por inserción ascendente.

Importante: un BST convencional no se equilibra automáticamente. Los árboles AVL y rojo-negro son ejemplos de estructuras especializadas que mantienen condiciones de equilibrio.

5.5 Aplicaciones en organización y búsqueda de información

Los árboles binarios se utilizan en diferentes áreas del desarrollo de software para representar relaciones, clasificar información y facilitar determinados procesos.

Búsqueda de registros

Permite organizar claves o identificadores para localizar información mediante comparaciones.

Organización de datos

Facilita mantener conjuntos dinámicos de elementos ordenados.

Expresiones matemáticas

Representa operadores y operandos para evaluar expresiones.

Árboles de decisión

Representa decisiones binarias que conducen a diferentes resultados.

Aplicación 1. Gestión de identificadores

Un sistema puede utilizar un BST para almacenar identificadores numéricos únicos. Cada identificador representa un registro que necesita consultarse posteriormente.

105   80   130   60   95   115   150

Estos valores pueden organizarse en un BST para facilitar las búsquedas y obtener listados ordenados.

Aplicación 2. Árboles de expresiones matemáticas

Los árboles binarios de expresión representan operadores mediante nodos internos y operandos mediante nodos hoja.

(5 + 3) × 2

Figura 6. Árbol binario de expresión matemática.

Primero se calcula la suma de 5 y 3. Después, el resultado se multiplica por 2.

(5 + 3) × 2 = 16

Estas estructuras se utilizan para representar y procesar expresiones en compiladores, intérpretes y sistemas de cálculo.

Aplicación 3. Árboles de decisión

Los árboles binarios pueden representar procesos donde cada decisión conduce hacia una de dos alternativas.

Una aplicación puede evaluar si una condición se cumple y dirigir el proceso hacia uno de dos posibles resultados.

Estos árboles se utilizan en sistemas de reglas, clasificación y algoritmos de aprendizaje automático. No necesariamente aplican las reglas de ordenamiento de los BST.

5.6 Resolución de problemas prácticos utilizando árboles binarios en Python

Los árboles binarios permiten resolver problemas relacionados con almacenamiento, organización y búsqueda de información.

Caso práctico: sistema de gestión de registros

Una aplicación necesita almacenar identificadores numéricos únicos. El sistema debe permitir registrar nuevos identificadores, buscar registros, eliminar elementos y mostrar los valores ordenados.

Para implementar la solución se utilizará un árbol binario de búsqueda mediante las clases Node y BinaryTree.

Código completo en Python

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None


class BinaryTree:
    def __init__(self):
        self.root = None

    def insert(self, value):
        self.root = self._insert(
            self.root, value
        )

    def _insert(self, node, value):
        if node is None:
            return Node(value)

        if value < node.value:
            node.left = self._insert(
                node.left, value
            )

        elif value > node.value:
            node.right = self._insert(
                node.right, value
            )

        return node

    def search(self, value):
        current = self.root

        while current is not None:
            if value == current.value:
                return True

            if value < current.value:
                current = current.left
            else:
                current = current.right

        return False

    def delete(self, value):
        self.root = self._delete(
            self.root, value
        )

    def _delete(self, node, value):
        if node is None:
            return None

        if value < node.value:
            node.left = self._delete(
                node.left, value
            )

        elif value > node.value:
            node.right = self._delete(
                node.right, value
            )

        else:
            if node.left is None:
                return node.right

            if node.right is None:
                return node.left

            successor = node.right

            while successor.left is not None:
                successor = successor.left

            node.value = successor.value

            node.right = self._delete(
                node.right, successor.value
            )

        return node

    def inorder(self):
        result = []
        self._inorder(self.root, result)
        return result

    def _inorder(self, node, result):
        if node is not None:
            self._inorder(node.left, result)
            result.append(node.value)
            self._inorder(node.right, result)

    def is_empty(self):
        return self.root is None


# Crear el árbol
tree = BinaryTree()

# Insertar identificadores
identifiers = [105, 80, 130, 60, 95, 115, 150]

for identifier in identifiers:
    tree.insert(identifier)

# Mostrar registros
print("Registros:", tree.inorder())

# Buscar identificadores
print("Buscar 95:", tree.search(95))
print("Buscar 200:", tree.search(200))

# Eliminar un identificador
tree.delete(80)

# Mostrar registros actualizados
print("Después de eliminar:", tree.inorder())

# Verificar si el árbol está vacío
print("Árbol vacío:", tree.is_empty())

Resultado esperado

Registros: [60, 80, 95, 105, 115, 130, 150]
Buscar 95: True
Buscar 200: False
Después de eliminar: [60, 95, 105, 115, 130, 150]
Árbol vacío: False

Explicación del funcionamiento

Creación

Se crea un objeto de la clase BinaryTree, inicialmente vacío.

Inserción

Los identificadores se incorporan mediante un ciclo y el método insert().

Búsqueda

search() comprueba si existe un identificador y devuelve True o False.

Eliminación

delete() retira un registro conservando las reglas del BST.

Visualización

inorder() devuelve los identificadores en una lista ordenada.

Validación

is_empty() determina si el árbol contiene elementos.

Ventajas de utilizar un BST

  • Permite almacenar identificadores únicos.
  • Mantiene una organización basada en comparaciones.
  • Facilita búsquedas sin examinar necesariamente todos los registros.
  • Permite insertar y eliminar elementos dinámicamente.
  • Proporciona valores ordenados mediante el recorrido inorden.
  • Facilita la organización del código utilizando clases y métodos.
La eficiencia depende de la altura del árbol. En estructuras con altura logarítmica, las operaciones fundamentales pueden realizarse en O(log n), mientras que en árboles degenerados pueden alcanzar O(n).

Comparación de los componentes implementados

Componente Responsabilidad Aplicación
Node Representar un nodo. Almacenar valores y referencias.
BinaryTree Administrar la estructura. Gestionar la raíz y las operaciones.
insert() Incorporar elementos. Registro de identificadores.
search() Localizar valores. Consulta de registros.
delete() Eliminar elementos. Retiro de registros.
inorder() Recorrer nodos. Listado ordenado.
is_empty() Verificar la estructura. Validación de árbol vacío.

Síntesis

La implementación de árboles binarios en Python permite representar estructuras jerárquicas mediante clases, objetos y referencias.

La clase Node representa los nodos, mientras que BinaryTree permite administrar la raíz y las operaciones fundamentales.

Los árboles binarios de búsqueda organizan los valores mediante comparaciones y permiten realizar inserciones, búsquedas, eliminaciones y recorridos ordenados.

Estas estructuras pueden aplicarse a la gestión de registros, el procesamiento de expresiones matemáticas, los árboles de decisión y diferentes problemas relacionados con la organización y búsqueda de información.
